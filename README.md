# Сайт лекций «Основы программирования»

Комплект для публикации всех лекций курса как одного статического сайта
со светлой и тёмной темой и оглавлением.

## Что здесь

```
.
├── shared/style.css          ← ЕДИНАЯ тема курса (цвета, типографика, рисунки)
├── tools/
│   ├── figtheme.py           ← графики matplotlib, адаптивные к теме
│   └── build_site.py         ← сборка всех лекций + генерация оглавления
├── lectures/
│   └── lec-01/
│       ├── slides.md         ← сама лекция
│       ├── style.css         ← @import '../../shared/style.css'
│       ├── make_figs.py      ← все графики лекции одним скриптом
│       ├── components/       ← сгенерированные Vue-компоненты графиков
│       └── pics/             ← растровые картинки (в двух версиях, если нужно)
├── .github/workflows/deploy.yml
└── dist/                     ← результат сборки (в git не коммитим)
```

## Быстрый старт

```bash
# 1. одна лекция в режиме правки
cd lectures/lec-01
npm install
npm run dev            # http://localhost:3030, клавиша d — смена темы

# 2. перегенерировать графики после правки данных
python make_figs.py

# 3. собрать весь сайт локально
cd ../..
python tools/build_site.py --base /
npx serve dist         # проверить, что оглавление и ссылки работают
```

## Новая лекция

```bash
cp -r lectures/lec-01 lectures/lec-02
```

и поправить в `lectures/lec-02/slides.md` три поля шапки: `title`, `lecture`, `topics` —
они попадают в оглавление сайта автоматически.

## Публикация

### GitHub Pages

Файл `.github/workflows/deploy.yml` уже готов. Нужно один раз:
Settings → Pages → Source: **GitHub Actions**. `--base` подставляется из имени
репозитория автоматически.

### GitVerse Pages (резервный контур)

GitVerse Pages публикует **готовую статику** и умеет собирать Jekyll; сборку Node
надёжнее делать заранее, а в GitVerse класть результат. Практичная схема:

1. основной репозиторий с исходниками — на GitHub (или локально);
2. отдельный репозиторий `kurs-pages` с содержимым `dist/`;
3. после сборки:

```bash
python tools/build_site.py --base /kurs-pages/
rsync -a --delete dist/ ../kurs-pages/
cd ../kurs-pages && git add -A && git commit -m "обновление" && git push
```

Так сайт живёт на двух площадках сразу, и ни одна из них не является
единственной точкой отказа. Ограничения GitVerse Pages: артефакт до 500 МБ,
один сайт на репозиторий, серверный код не поддерживается — для слайдов этого
с запасом хватает.

> **Важно про размер.** Не кладите в репозиторий экспортированные PDF лекций
> (у вас они по 12–19 МБ каждая). Репозиторий должен содержать только исходники;
> PDF — артефакт сборки. В `.gitignore`: `*.pdf`, `dist/`, `node_modules/`.

## Светлая и тёмная тема — как это устроено

Slidev при переключении темы вешает класс `.dark` на `<html>`. Поэтому:

- **все цвета** объявлены токенами в `shared/style.css` — один блок `:root`
  (светлая) и один `html.dark` (тёмная);
- **в слайдах цвет не пишется напрямую** — только `var(--brand)`, `var(--ink)`
  и т. п. Слайд, написанный по этому правилу, автоматически корректен в обеих темах;
- `colorSchema: auto` в шапке лекции — слайды подхватывают системную тему
  студента, клавиша `d` переключает вручную.

### Графики

`tools/figtheme.py` решает главную проблему: matplotlib рисует служебными
цветами-маркерами, а на выходе они заменяются на CSS-значения —
обвязка графика на `currentColor`, серии данных на `var(--s1)`…`var(--s8)`.
Получается **один файл** графика, корректный в обеих темах, без второй копии.

Работает это только для инлайнового SVG, поэтому `save_adaptive()` дополнительно
кладёт готовый Vue-компонент в `components/`, а Slidev подхватывает его сам:

```md
<FigCp class="w-[520px] mx-auto" />
```

Палитра `--s1…--s6` проверена на различимость при протанопии, дейтеранопии
и тританопии отдельно для светлой и тёмной подложки. Менять её можно только
целым набором, не по одному цвету.

### Растровые картинки

Скриншоты и схемы из drawio так не переключить — для них есть встроенный
компонент Slidev:

```md
<LightOrDark>
  <template #light><img src="./pics/ide-light.png"></template>
  <template #dark><img src="./pics/ide-dark.png"></template>
</LightOrDark>
```

Для монохромных схем есть быстрый костыль `class="invert-on-dark"` —
но лучше постепенно переводить схемы в SVG.

## Экспорт PDF

```bash
cd lectures/lec-01
npm run export:pdf          # светлая версия
npm run export:pdf-dark     # тёмная версия
```

PDF нужен как резерв на случай отсутствия интернета в аудитории — но основной
формат для студентов теперь сайт.
