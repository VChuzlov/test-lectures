# Основы программирования: Python для химиков-технологов

Репозиторий с презентациями лекций. Каждая лекция — статический сайт на базе [Slidev](https://sli.dev).

## Структура

- `lectures/` — папки с лекциями
- `lectures/01-intro/` — первая лекция (и так далее)

## Как смотреть

Лекции опубликованы в GitLab Pages:
`https://ваш-домен/ваш-проект/lectures/01-intro/`

## Как запустить локально

```bash
cd lectures/01-intro
npx slidev slides.md
```
