## Сквозная задача

Те же шесть уравнений, что в лекции 7. Там ошибки нашли вручную, а программу
на два десятка строк с пятью уровнями вложенности со слайдов убрали
(решение 15.10.2026). Здесь та же программа разложена на функции, каждая —
один простой цикл или композиция вызовов.

| Функция | Шаг плана | Что делает |
|---|---|---|
| `is_balanced(equation)` | 1 и 5 | делит по стрелке, сравнивает составы частей |
| `count_atoms(side)` | 2 и 5 | делит по «+», умножает на коэффициент, складывает |
| `split_coef(term)` | 3 | `'3O2'` → `(3, 'O2')`; `for` и `break` |
| `parse_formula(formula)` | 4 | `'C2H6'` → `Counter({'H': 6, 'C': 2})` |
| `split_elements(formula)` | 4 | `'KClO3'` → `['K', 'Cl', 'O3']` |
| `split_symbol(part)` | 4 | `'O3'` → `('O', 3)` |

- Слайд 2: зал диктует план проверки. Пять шагов — будущие функции.
- Слайд 3: верхний уровень записан сразу, будто `count_atoms()` уже есть.
- Слайд 16: `split_coef()`, пример функции с двумя результатами.
- Слайды 25–29: дерево вызовов, затем функции снизу вверх. На слайдах 27–31
  под заголовком строка с положением функции в дереве (`.crumb`).
- Слайд 30: проверки `assert`; последняя (CuSO₄·5H₂O) не проходит.
- Слайд 31: программа слайда 3 выполняется; `parse_formula()` вызывается
  22 раза. Разность `Counter` для уравнения № 2 — `Counter({'O': 1})`.
- Слайд 32, поворот: кристаллогидрат даёт «элемент» `O·` с индексом 45.
  Исправление — одна строка `side.replace('·', ' + ')` в `count_atoms()`.
- Слайд 33: `molar_mass(formula)` — вызов `mass(count_atoms(formula))`,
  то есть функции со слайда 7 и функции разбора.

Ограничение, названное на слайде 33: формулы со скобками (CO(NH₂)₂) функции
разбора не поддерживают. Готовое задание повышенной сложности для ЛБ.
