# Как писать цвет в слайдах

Никогда не пишите цвет напрямую — берите токен, и слайд сам подстроится под тему:

```md
<!-- ❌ так делать нельзя: на светлой теме будет нечитаемо -->
<span style="color: #2bb671">Важно</span>

<!-- ✅ так правильно -->
<span class="text-[var(--brand)]">Важно</span>
```

Доступные токены объявлены в `shared/style.css`:

<div class="small-table">

| Токен | Назначение |
|---|---|
| `--ink`, `--ink-2`, `--ink-muted` | основной / вторичный / приглушённый текст |
| `--surface`, `--surface-2` | фон слайда и фон блоков |
| `--brand`, `--brand-2` | фирменный зелёный (свой шаг для каждой темы) |
| `--s1` … `--s8` | цвета серий на графиках |

</div>

# Картинки: три способа пережить смену темы

<div grid="~ cols-3 gap-4">

<div>

### 1. График matplotlib

Один SVG, оба режима. Генерируется скриптом:

```python
from figtheme import use_adaptive, save_adaptive
use_adaptive()
...
save_adaptive(fig, 'pics/cp')
```

Вставка компонентом:

```md
<FigCp class="w-[520px]" />
```

</div>

<div>

### 2. Две версии картинки

Для схем из drawio, скриншотов IDE:

```md
<LightOrDark>
  <template #light>
    <img src="./pics/ide-light.png">
  </template>
  <template #dark>
    <img src="./pics/ide-dark.png">
  </template>
</LightOrDark>
```

</div>

<div>

### 3. Инверсия «на скорую руку»

Для чёрно-белых схем, которые некогда перерисовывать:

```md
<img src="./pics/scheme.png"
     class="invert-on-dark">
```

Работает только для монохромных картинок.

</div>

</div>
